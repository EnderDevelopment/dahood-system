# Dahood System

Enhance your FiveM experience with Dahood System

## Features

- **Silent Aim**: Improve your aiming accuracy silently.
- **ESP (Extra Sensory Perception)**: See players through walls and obstacles.
- **Fog Changer**: Customize the fog effect in your game.
- **Head Invisibility**: Make your head invisible to others.
- **Hitbox Expander**: Expand your hitbox for better targeting.
- **Customizable Radius**: Adjust the detection radius for features like ESP and Silent Aim.
- **Adjustable Visibility**: Control your visibility to other players.

## Requirements

- FiveM Server
- ESX Framework
- MySQL Database

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start dahood-system` to your server.cfg file.
4. Ensure you have the required dependencies installed.

## Usage

1. Press F1 to open the Dahood System menu.
2. Toggle features on or off using the checkboxes.
3. Adjust settings like radius and visibility using the sliders.

## Configuration

Customize the GUI and feature settings in the `config.lua` file.
